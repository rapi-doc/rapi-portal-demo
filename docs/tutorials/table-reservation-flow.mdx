# Tutorial: Building a Table Reservation UI

Learn how to integrate the BrewCraft Reservations API to create an interactive table booking widget.

<Callout type="tip">
Reservations open 14 days in advance at 8:00 AM local time.
</Callout>

---

## 1. Checking Availability

Before displaying time buttons to your users, fetch the open slots for their party size:

<Tabs>
  <TabItem label="Request">
```http
GET /v1/reservations/availability?date=2026-10-25&partySize=4&seatingArea=patio HTTP/1.1
Host: api.brewcraft.io
```
  </TabItem>
  <TabItem label="Response">
```json
{
  "date": "2026-10-25",
  "availableSlots": [
    "12:00",
    "13:30",
    "15:00",
    "18:00",
    "19:30"
  ]
}
```
  </TabItem>
</Tabs>

---

## 2. Seating Area Options

| Seating Area | Description | Best For |
| :--- | :--- | :--- |
| **Indoor** | Cozy booth and cafe table seating with acoustic music. | Work & Meetings |
| **Patio** | Outdoor heated garden patio with greenery. | Sunny afternoons & pets |
| **Window** | High-top counter facing the avenue. | Solo visitors & reading |
| **Bar** | Front-row counter right in front of the La Marzocco espresso machines. | Coffee enthusiasts |

---

## 3. Submitting the Reservation

Once the guest picks a time slot, call `POST /reservations` with their contact details. A confirmation email and SMS reminder are dispatched automatically.
